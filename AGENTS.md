# Repository instructions

Read and follow `CONTRIBUTING.md` before changing this project.

- Use English for all repository content: documentation, comments, identifiers, filenames, game UI, and collaboration text such as commit messages and pull requests.
- A user's conversation language does not change the repository language. Do not add translated companion documents.
- Use Unicode escapes for non-English input-test fixtures and explain their purpose in English.
- Preserve existing gameplay and unrelated local changes when editing documentation or language.
